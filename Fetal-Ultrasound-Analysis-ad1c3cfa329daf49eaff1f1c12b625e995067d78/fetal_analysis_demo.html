About This System

What is Automated Fetal Ultrasound Analysis?

This AI-powered system uses YOLOv8 deep learning to automatically classify fetal ultrasound images into anatomical planes. It assists prenatal screening by identifying structures like the fetal brain, abdomen, femur, thorax, and more.

Trained on the BCNatal Maternal-Fetal Ultrasound Dataset (12,400+ images from Zenodo), the model achieves high accuracy in distinguishing between different anatomical views.

The system supports both YOLOv8 Detection (bounding boxes) and YOLOv8 Classification (plane classification) modes.
